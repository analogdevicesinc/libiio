FwuStatus

enum iio.FwuStatus

Progress of a firmware upload instance.

Values:

Idle

No upload in progress.

Receiving

The device is receiving the image.

Preparing

The device is preparing to program the image.

Transferring

The image is being transferred to the device.

Programming

The device is being programmed.
